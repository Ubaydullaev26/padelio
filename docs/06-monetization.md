# 06 · Монетизация

## Контекст и главный принцип

⚠️ Рынок Ташкента на старте мал (оценка GMV $1.5–5 млн/год, док. 02). Значит: (1) монетизация не должна тормозить захват рынка — сначала покрытие и привычка, потом выжимание; (2) нужно несколько источников, а не только комиссия; (3) модель должна быть «мягкой» к клубам — их всего ~20, потеря каждого критична.

**Принцип: клубу должно быть выгоднее быть в Padelio, чем вне его, даже с учётом комиссии.** Ценность = новые клиенты + убитый no-show + сэкономленный ФОТ + аналитика.

## Эволюция модели по фазам

### Фаза 1 (запуск, месяцы 0–6): «Всё почти бесплатно»
- SaaS-админка для клуба — **бесплатно навсегда** (базовый тариф). Это троянский конь полноты данных.
- Комиссия с онлайн-броней: **0–5%** на старте (промопериод), только чтобы приучить к модели.
- Цель фазы — не выручка, а покрытие ≥80% кортов и доля онлайн-оплат ≥60%.

### Фаза 2 (рост, месяцы 6–18): включаем основные источники
1. **Комиссия с брони (основной источник).** Целевой take rate: **7–10%** с броней, приведённых платформой. Дифференциация, снимающая страх «продаёте мне моих клиентов»: бронь клиента, пришедшего по прямой ссылке/QR клуба — комиссия 2–3% (как эквайринг+сервис); бронь из общего каталога/карты — полная комиссия. Прозрачная атрибуция в отчёте клуба.
2. **SaaS-подписка клуба (тарифы).** Free: расписание, брони, 1 админ. **Pro (~$50–100/мес):** аналитика, динамические цены, промокоды клуба, абонементы, несколько админов, приоритетная поддержка. **Business:** сеть клубов, API, кастомные отчёты.
3. **Продвижение клубов:** платное поднятие в выдаче (помечено «Промо» — честность к пользователю), баннер на главной, рассылка по подписчикам района (строго opt-in). Аукционная модель не нужна при 20 клубах — фиксированные пакеты.
4. **Комиссия с допуслуг:** аренда ракеток/мячей, записи к тренерам (10–15% с тренировки — тренер получает клиентов и учёт).

### Фаза 3 (зрелость, 18+ мес.): расширение
5. **Padelio Premium** (подписка игрока, док. 05 §17) — только после доказанной частоты использования.
6. **Турниры:** организационный сбор с участника (10–20%), спонсорские пакеты, платные лиги.
7. **Маркетплейс инвентаря:** партнёрские продажи ракеток/кроссовок/формы (аффилиат 5–15% или собственный сток под заказ). Точка входа: «понравилась арендованная ракетка — купи со скидкой».
8. **Партнёрские программы:** спортивные бренды, страховки, фитнес, банки (кобрендовые акции), корпоративные программы (компании покупают игровые часы для сотрудников — B2B2C, потенциально крупный чек).
9. **Реклама** — осторожно: только нативные форматы (партнёрские подборки, спонсор турнира). Баннерная реклама сторонних брендов в MVP-интерфейсе запрещена — разрушает доверие и премиальность.
10. **Данные и инсайты** (агрегированные, анонимные): отчёты для инвесторов в падел-инфраструктуру «где строить следующий клуб». Нишевый, но маржинальный продукт.

## Юнит-экономика (модель для проверки, цифры-гипотезы)

- Средний чек брони: 300 000 сум (~$24).
- Take rate смешанный: 6%. Доход с брони ≈ $1.4.
- Эквайринг платёжных систем UZ: ~1–2% → маржа с брони ≈ $1.0–1.2.
- Активный игрок: 4–6 броней/мес → $4–7/мес дохода с игрока.
- 2 000 активных игроков (реалистичный потолок года 1) → $8–14k/мес с комиссий + SaaS (20 клубов × 30% на Pro × $75 = ~$0.5k) + допуслуги/промо ≈ **$10–17k/мес**. Хватает на компактную команду в УЗ — но не более. Вывод: для венчурной траектории обязательна экспансия (города/виды спорта) — закладывается в архитектуру с первого дня.

## Анти-паттерны (чего НЕ делаем)

- Не берём комиссию с «оплаты на месте» на старте (невозможно проконтролировать — породит скрытие броней).
- Не поднимаем take rate выше ценности: комиссия > 12–15% на малом рынке → клубы строят обходные пути.
- Не продаём пользовательские данные третьим лицам. Никогда.
- Не делаем платным то, что было бесплатным, без grandfathering для ранних клубов.

## KPI монетизации

Take rate эффективный, ARPU игрока, ARPC клуба (average revenue per club), доля онлайн-оплат, доля Pro-подписок клубов, GMV/мес, маржа после эквайринга.
