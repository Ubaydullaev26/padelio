# 07 · Роли, права и админ-панели

## 1. Модель ролей (RBAC)

Один человек = один аккаунт (Telegram ID); роли назначаются поверх аккаунта и могут совмещаться (владелец клуба тоже играет). Роли клубного уровня привязаны к конкретному клубу: пользователь может быть админом двух клубов.

| Роль | Область | Кто назначает |
|---|---|---|
| `player` | глобально (по умолчанию) | автоматически |
| `coach` | глобально + привязки к клубам | платформа (верификация) по заявке |
| `club_admin` | конкретный клуб | владелец клуба |
| `club_owner` | конкретный клуб / сеть клубов | платформа при онбординге клуба |
| `platform_support` | платформа | админ платформы |
| `platform_moderator` | платформа | админ платформы |
| `platform_admin` | платформа | суперадмин |
| `platform_superadmin` | платформа | учредители |

## 3. Панель администратора клуба (рабочее место смены)

Форм-фактор: режим в том же Mini App + адаптивная веб-версия (планшет на стойке).

- **Экран «Сегодня» (главный):** сетка корты × время, цветовые статусы (свободно / бронь онлайн / бронь на месте не оплачена / check-in / завершено / блок). Живое обновление.
- Быстрая бронь по звонку: тап по слоту → имя + телефон → готово (≤15 сек).
- Карточка брони: клиент, статус оплаты, кнопки check-in / принять оплату / отменить / no-show / перенести.
- Очередь подтверждений «оплата на месте» (с таймером).
- Блокировки слотов: разовая и периодическая (ремонт, своя секция, турнир), с причиной.
- Поиск броней по имени/телефону/коду; календарь на будущие дни.
- Ответы на отзывы; уведомления о новых бронях/отменах.

## 4. Панель владельца клуба

Всё, что у админа, плюс:

- **Дашборд:** выручка (день/неделя/месяц), загрузка кортов по часам (тепловая карта), доля онлайн-оплат, no-show, новые/повторные клиенты, средний чек, динамика к прошлому периоду.
- **Настройки клуба:** карточка (фото, описание, услуги, контакты, часы), корты (добавление, характеристики, временное закрытие), тарифная сетка (базовые цены, прайм/офф-пик, будни/выходные, праздники), политика отмены (выбор шаблона), горизонт бронирования, включение «оплаты на месте», шаг сетки.
- **Маркетинг:** промокоды клуба, динамические скидки офф-пика («будни до 17:00 −30%»), абонементы (конструктор), заказ продвижения.
- **Сотрудники:** приглашение/отключение админов (по ссылке-инвайту), права, лог действий сотрудников.
- **Финансы:** отчёт по выплатам от платформы (онлайн-оплаты минус комиссия), реестр транзакций, счета-фактуры, реквизиты.
- **Тренеры клуба:** привязка/отвязка тренеров, расписание тренерских слотов.
- Для сетей: переключатель клубов + сводный дашборд.

## 5. Панель платформы (наша команда)

Форм-фактор: отдельное веб-приложение (не Mini App) с 2FA.

- **Онбординг клубов:** заявки, чек-лист запуска (фото, тарифы, договор, обучение админа), активация.
- **Каталог:** модерация карточек, категории услуг, порядок ранжирования, geo-данные.
- **Пользователи:** поиск, история, ограничения/баны, объединение дублей, надёжность (no-show score).
- **Брони и платежи:** глобальный реестр, инструменты споров (лог событий брони), ручные возвраты, сверка с платёжными провайдерами (reconciliation, док. 12 §2).
- **Выплаты клубам:** расчёт (GMV − комиссия), реестры выплат, статусы, экспорт для бухгалтерии.
- **Модерация:** очередь отзывов по жалобам, жалобы на клубы/игроков, фото.
- **Поддержка:** тикеты (интеграция с Telegram-чатом поддержки), макросы, SLA-таймеры.
- **Маркетинг:** платформенные промокоды, рефералка (параметры, антифрод-алерты), push-кампании (сегменты, троттлинг), баннеры.
- **Аналитика платформы:** North Star (завершённые брони/нед), GMV, take rate, покрытие, retention-когорты, воронка бронирования, метрики клубов (скорость подтверждения, отмены).
- **Конфигурация:** все параметры из док. 05 (длительность hold, окна отмен по умолчанию, лимиты, комиссии по клубам), фиче-флаги.
- **Здоровье системы:** статус платёжек, очередь недоставленных уведомлений, ошибки.
