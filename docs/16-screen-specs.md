# 16 · Дизайн-концепция: спецификации ключевых экранов

Текстовые wireframe-спецификации 6 ключевых экранов MVP — задание дизайнеру и разработчикам. Общие принципы: тема Telegram (светлая/тёмная из `--tg-theme-*`), один основной CTA на экран, «большой палец» — ключевые действия в нижней трети, узбекский/русский тексты проектируются одновременно (узбекские строки длиннее — закладывать запас).

Главная кнопка Telegram (**MainButton**, нативная нижняя кнопка Mini App) используется как основной CTA на всех шагах воронки — это привычный для пользователя Telegram паттерн.

---

## 1. Главный экран (Discovery)

```
┌──────────────────────────────┐
│ [Сегодня ▾] [19:00–21:00 ▾] │  ← контекст поиска (дата/время), sticky
│ [Список|Карта]   [Фильтры ⚙]│  ← сегмент-контрол + фильтры (bottom-sheet)
├──────────────────────────────┤
│ ┌──────────────────────────┐ │
│ │ фото   PadelPro  ★4.8    │ │  карточка клуба:
│ │ Юнусабад · 2.3 км        │ │  фото 16:9, название, рейтинг,
│ │ от 250 000 сум/час       │ │  район+расстояние, цена «от»
│ │ [19:00] [20:30] [21:00]  │ │  ← чипы ближайших слотов — тап
│ └──────────────────────────┘ │    ведёт СРАЗУ в бронирование
│ ┌ Matchpoint ★4.6 … ┐        │
├──────────────────────────────┤
│  Играть · Мои брони · Профиль│  ← таббар (раздел «Матчи» — v3)
└──────────────────────────────┘
```

- Чипы слотов на карточке — главный ускоритель: «3 тапа до корта» начинается с главного экрана.
- Режим «Карта»: пины с ценой «от»; тап → мини-карточка снизу (фото, рейтинг, слоты-чипы) → свайп вверх = полная карточка.
- Сортировка списка: скор релевантности = наличие слотов в выбранное время → расстояние → рейтинг. Избранные — приоритет.
- Состояния: скелетоны карточек; пусто → «Сбросить фильтры» + ближайшие альтернативные времена; нет гео → сортировка по рейтингу.

## 2. Карточка клуба

Порядок блоков — по частоте использования, бронь доступна с первого экрана без скролла:

1. Галерея фото (свайп, 16:9) + кнопка «назад» поверх.
2. Название, ★рейтинг (тап → отзывы), район, «2.3 км».
3. **Блок «Ближайшее время»**: горизонтальные чипы слотов на выбранную дату + строка дат (14 дней). Тап по чипу → экран бронирования. Это главный CTA.
4. Цены: компактная таблица прайм/офф-пик × будни/выходные.
5. Услуги: сетка иконок с подписями (парковка, душ, кафе, аренда ракеток/мячей, раздевалка, кондиционер).
6. Корты: «Корт 1 · indoor · панорама» (фото по тапу).
7. Отзывы: сводка (★4.8 · 127) + 3 последних + «Все отзывы».
8. Адрес: мини-карта (статичная картинка — не грузим JS-карту), кнопка **«Маршрут»** → выбор Яндекс/Google/2GIS, кнопки «Позвонить» и «Telegram клуба».
9. Часы работы, правила отмены (шаблон клуба, человеческим языком).

MainButton: «Выбрать время» (скролл к блоку 3 / открытие расписания).

## 3. Выбор слота и длительности

```
┌──────────────────────────────┐
│ ← PadelPro     [Пт 18 июл ▾] │
│ [17][18][19][20][21] июля    │  ← лента дат
├──────────────────────────────┤
│        18:00 19:00 20:00 21:0│
│ Корт 1  250к  ███   250к  ██ │  ← сетка: строка=корт
│ Корт 2  250к  250к  ███  300к│    ███ = занято (серый)
│ Корт 3 (отк.) 200к  200к 200к│    цена = свободно (акцент)
├──────────────────────────────┤
│ Выбрано: Корт 2 · 19:00      │  ← панель выбора
│ Длительность: [60] [90] [120]│
│ + Ракетки (2 × 30к) [+][2][–]│  ← допуслуги, степперы
│ + Мячи (1 × 25к)    [+][1][–]│
├──────────────────────────────┤
│ MainButton: «Далее · 360 000»│  ← сумма живая
└──────────────────────────────┘
```

- Обновление в реальном времени: занятый другим слот сереет без перезагрузки; выбранный пользователем слот, ставший занятым → toast «Это время только что заняли» + подсветка альтернатив (E1).
- Недоступные длительности (следующий слот занят) — задизейблены с подсказкой.
- Прошедшее время скрыто; блокировки клуба — «недоступно» без причины.

## 4. Подтверждение и оплата (checkout)

- Сводка-чек: клуб, корт, дата словами («пятница, 18 июля»), время, длительность, допуслуги, строка «Промокод» (сворачиваемая), итог крупно.
- Правила отмены — одной строкой с иконкой: «Бесплатная отмена до 17 июл 19:00».
- Если телефона нет → системный диалог Telegram «Поделиться номером» (объяснение: «номер нужен клубу для брони»).
- Способ оплаты: радио-карточки «Payme», «Click», «Оплата в клубе» (если разрешена; с пометкой «требует подтверждения клуба»).
- MainButton: «Оплатить 360 000 сум» → таймер hold виден: «Слот удержан за вами · 9:41».
- Ошибка оплаты → остаёмся на экране, hold продолжает тикать, баннер с причиной + «Попробовать ещё раз / выбрать другой способ» (E3).

**Экран успеха:** анимация-галочка (confetti — уместно), карточка брони с QR и коротким кодом (`PD-4F7K`), кнопки: «Поделиться с друзьями» (нативный форвард Telegram — карточка с deep-link), «Добавить в календарь» (.ics), «Маршрут». MainButton: «К моим броням».

## 5. Мои брони / карточка брони

- Табы «Предстоящие / Прошедшие». Карточка: статус-бейдж (Подтверждена / Ждёт подтверждения клуба с таймером / Отменена / Сыграна / Неявка), клуб, корт, время, сумма.
- Карточка брони: QR крупно (яркость экрана — подсказка), участники (v2), действия по статусу (матрица — док. 04 §5). «Отменить» → bottom-sheet: правила клуба + **расчёт возврата до подтверждения** («Вернём 360 000 сум на карту Payme») + двойное подтверждение.
- Прошедшая бронь: «Оценить ★», **«Повторить»** (главная кнопка — тот же клуб/корт/время на следующую неделю).
- Пустое состояние «Предстоящих»: иллюстрация + «Найти корт» → главный экран.

## 6. Режим клуба: экран «Сегодня» (админ)

```
┌──────────────────────────────┐
│ PadelPro · Сегодня, 18 июл   │
│ [← вчера] [Сегодня] [завтра→]│
│ ⏳ Ждут подтверждения: 2     │  ← красный бейдж, тап → очередь
├──────────────────────────────┤
│       Корт 1   Корт 2  Корт 3│
│ 09:00  ──       ──      ──   │  ← пусто: тап = быстрая бронь
│ 10:00 [Аziz    ──      ──    │  🟢 оплачено онлайн
│        🟢✓]                  │  ✓ = check-in сделан
│ 11:00  ──     [Тимур   ──    │  🟡 оплата на месте (не оплачено)
│                🟡]           │  🔴 no-show   ⬛ блокировка
├──────────────────────────────┤
│ [🔍 Поиск]  [+ Бронь]  [⬛ Блок]│
└──────────────────────────────┘
```

- **Быстрая бронь (≤15 сек):** тап по пустой ячейке → sheet: имя (обяз.), телефон (опц.), длительность [60|90|120], «Оплата: на месте/уже оплачено» → «Создать». Автоподстановка постоянных клиентов по первым буквам.
- Тап по брони → sheet: клиент (имя, телефон — кнопка звонка), статус оплаты, действия: **Check-in** (главная, зелёная) / Принять оплату / Перенести / Отменить (причина обязательна) / No-show (доступна через 15 мин после начала, с подтверждением).
- Очередь подтверждений: карточки с таймером «осталось 1:43:12», кнопки Подтвердить/Отклонить.
- Живое обновление: новая онлайн-бронь появляется в сетке сама + звук/вибро (настраивается).
- Оффлайн на стойке: баннер «Нет соединения — изменения сохранятся при подключении», действия копятся в локальной очереди.

## Дизайн-система (минимум для MVP)

- **Токены:** цвета от `--tg-theme-*` + акцент бренда (рекомендация: тёплый жёлто-зелёный «падел-мяч» #C6E84A на тёмном / #7CB518 на светлом — проверить контраст WCAG AA); радиусы 12/16; отступы кратны 4.
- **Компоненты:** карточка клуба, чип слота (5 состояний: свободен/занят/выбран/прошёл/held), степпер допуслуг, статус-бейдж брони (7 статусов), bottom-sheet, toast, скелетоны, пустые состояния (3 иллюстрации), QR-карточка.
- **Типографика:** системный шрифт (SF/Roboto — скорость загрузки), 3 размера + моно для кодов броней.
- Иконки услуг — единый набор (lucide), суммы — всегда с разрядами: «250 000 сум».
