# Чек-лист вопросов юристу (Узбекистан)

Цель — до разработки получить письменные ответы по каждому пункту: «нет блокера / есть требования (какие) / блокер». Ответы влияют на PRD (кошелёк, фискализация, оферта).

## 1. Форма и статус бизнеса
- [ ] Оптимальная форма: ООО / ИП; налоговый режим для комиссионной модели (в т.ч. статус ИТ-компании, резидентство IT Park Uzbekistan — льготы, требования, применимость к маркетплейсу).
- [ ] ОКЭД/виды деятельности для агрегатора бронирований и приёма платежей в пользу третьих лиц.

## 2. Модель агрегатора и договоры
- [ ] Кто продавец услуги аренды корта — клуб (наша позиция) или платформа? Последствия для чеков, НДС, ответственности.
- [ ] Агентский договор с клубом: приём оплаты платформой в пользу клуба — допустимость, требования, периодичность выплат.
- [ ] Публичная оферта для игроков: правила бронирования, отмен, возвратов, no-show — соответствие закону «О защите прав потребителей» (вправе ли мы удерживать 100% при поздней отмене?).
- [ ] Ответственность платформы при отмене брони клубом / травме на корте (разграничение).

## 3. Платежи и фискализация
- [ ] Онлайн-фискализация (ОФД): кто выбивает чек — клуб или платформа-агент? Технические провайдеры фискализации, совместимые с Payme/Click.
- [ ] Условия подключения Payme / Click / Uzum для модели агрегатора (сплит-платежи? выплаты клубам? холдирование?).
- [ ] Возвраты: сроки и порядок по закону; частичные возвраты.
- [ ] **Кошелёк (внутренний баланс):** законность предоплаченного баланса небанковской организацией; лимиты; нужна ли лицензия / договор с платёжной организацией. (Если блокер — MVP живёт без кошелька, см. док. 05 §11.)
- [ ] Подарочные сертификаты: требования к срокам действия и возвратам.

## 4. Персональные данные
- [ ] Закон «О персональных данных» РУз: регистрация базы ПДн, требование локализации (хранение на серверах в УЗ?) — критично для выбора хостинга!
- [ ] Минимальный состав ПДн (имя, телефон, Telegram ID) — какие согласия и в какой форме собирать в Mini App.
- [ ] Передача ПДн клубам (имя+телефон для брони) — как оформить.
- [ ] Трансграничная передача (серверы/сервисы за рубежом, если локализация мягкая).

## 5. Прочее
- [ ] Товарный знак «Padelio» — проверка и регистрация (УЗ + классы: ПО, спортуслуги).
- [ ] Реферальные вознаграждения и промокоды — налоговые последствия для получателей (НДФЛ с бонусов?).
- [ ] Требования к рекламным рассылкам (спам-регулирование, согласие).
- [ ] Договор с самозанятыми тренерами (фаза 2) — форма отношений.
- [ ] Условия использования Telegram Mini Apps / Telegram Payments — соответствие нашей модели правилам платформы (юрист + продакт вместе).

## Формат результата
Меморандум 2–4 страницы: по каждому пункту — вывод, требования, стоимость/сроки исполнения, влияние на продукт. Блокеры и требования переносятся в PRD (док. 14 §10) и Roadmap.
