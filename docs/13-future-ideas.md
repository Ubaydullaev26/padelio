# 13 · Идеи для будущего (бэклог из 60+ функций)

Не обещания, а копилка. Каждая идея перед реализацией проходит фильтр: спрос → влияние на North Star → стоимость. Сгруппированы по темам.

## Игра и матчмейкинг
1. **Открытые матчи** — бронируешь корт, открываешь 1–3 места, платформа находит игроков твоего уровня (killer-фича retention Playtomic).
2. **Поиск партнёра** — «ищу пару на вторник вечером, уровень 3.0», лента заявок.
3. **Матчмейкинг по уровню** — автоподбор четвёрок Elo-алгоритмом.
4. **Рейтинг игрока 1.0–7.0** — подтверждённый результатами матчей.
5. **Подтверждение счёта матча** обоими сторонами + история личных встреч.
6. **Лиги** — сезонные дивизионы с повышением/вылетом, матчи в удобное время недели.
7. **Турниры** — конструктор сеток (олимпийка, группы+плей-офф, американо, мексикано), онлайн-регистрация, взносы, автоматическое расписание кортов.
8. **Корпоративные лиги** — компании выставляют команды (B2B-продажи).
9. **«Играю сейчас»** — кнопка спонтанной игры: кто свободен в ближайшие 2 часа рядом.
10. **Гостевой режим** для друга без Telegram — именной QR-пропуск.

## ИИ и данные
11. **ИИ-рекомендации слотов** — «вы обычно играете вт 20:00 — на завтра свободен ваш корт».
12. **Прогноз загрузки для клубов** — когда ставить скидки, ML по истории.
13. **Динамическое ценообразование** — автопилот цен клуба (surge/discount) с границами, заданными владельцем.
14. **ИИ-ассистент в боте** — «найди корт на завтра вечером до 300к рядом с Юнусабадом» естественным языком (uz/ru).
15. **ИИ-анализ отзывов** — авто-саммари сильных/слабых сторон клуба.
16. **Предсказание no-show** — скоринг риска, депозит только рискованным.
17. **Умное расписание тренера** — оптимизация окон между занятиями.
18. **Авторефери уровня** — корректировка рейтинга по косвенным сигналам (с кем играет, счёт).

## Видео и медиа
19. **Видеозапись матчей** — камеры в клубах, автоклипы по QR брони (партнёрская модель с клубами).
20. **Хайлайты ИИ** — автонарезка лучших розыгрышей, шеринг в Telegram/Instagram.
21. **Стриминг турниров** внутри Mini App.
22. **Видеоаналитика техники** — «разбор с тренером» по записи (платно).
23. **Фотозоны и авто-фото после матча** — вирусный маркетинг.

## Социальная сеть и комьюнити
24. Профиль игрока: статистика, стиль (правый/левый корт), достижения.
25. Друзья и подписки, лента активности («Тимур сыграл в PadelPro»).
26. Чаты матчей и клубные сообщества внутри платформы.
27. Ачивки и бейджи («первая победа», «10 недель подряд», «ночной игрок»).
28. Челленджи месяца (сыграй 8 игр — получи бонус) и стрики.
29. Таблицы лидеров: клуб / район / город.
30. Клубные события: мастер-классы, вечеринки, «падел+бранч» с записью.
31. Блог/гайды: правила, техника, словарь падела (SEO + обучение новичков).
32. **Женские/детские комьюнити-разделы** — отдельные лиги и события.

## Тренеры и обучение
33. Маркетплейс тренеров: рейтинг, сертификация, видеовизитки.
34. Групповые тренировки и школы (запись в группу, абонемент на секцию).
35. Академия для детей: расписание, прогресс ребёнка для родителей.
36. План развития игрока: цели, домашние задания от тренера.
37. Онлайн-курсы и видеоуроки (партнёрство с топ-тренерами).
38. **Сплит-оплата тренировки** группой учеников.

## Коммерция
39. Маркетплейс инвентаря: ракетки, мячи, форма (аффилиат/сток).
40. «Понравилась арендованная ракетка → купи со скидкой» (данные аренды!).
41. Trade-in ракеток и барахолка комьюнити.
42. Перетяжка/ремонт, кастомизация грипов — запись к мастеру.
43. Кафе клуба: предзаказ еды/воды к матчу из Mini App.
44. Корпоративные пакеты: компания покупает часы для сотрудников (wellness-бюджеты).
45. Страховка от травм в один тап при брони (партнёр-страховщик).
46. Подарочные наборы «первая игра» (корт + ракетки + тренер 30 мин).

## Для клубов
47. Полноценный CRM клуба: сегменты клиентов, рассылки, реактивация «уснувших».
48. Программа лояльности клуба (штампы: 10-я игра бесплатно).
49. Управление персоналом: смены, KPI админов.
50. Бенчмарки рынка: «ваша загрузка против средней по городу» (анонимно).
51. API/виджет бронирования для сайта и Instagram клуба.
52. Табло-режим: экран в клубе с расписанием дня и QR.
53. Умные замки/освещение: доступ на корт по QR брони без админа (ночные слоты!).
54. Консалтинг по данным для инвесторов: «где строить следующий клуб».

## Платформа и экспансия
55. Мультиспорт: теннис, бадминтон, сквош, настольный теннис (модель уже готова).
56. Мультигород: Самарканд, Бухара → Алматы, Бишкек, Баку.
57. PWA/нативные приложения — когда аудитория потребует.
58. Интеграция с международными рейтингами (Playtomic level import, FIP).
59. Падел-туризм: пакеты «игра + гость города» для приезжих, аренда экипировки.
60. Белая метка (white label) движка бронирования для других стран/операторов.
61. Кросс-промо с фитнес-приложениями и банковскими суперappами UZ.
62. Углеродно-нейтральные слоты/социальные программы (детям — бесплатные офф-пик часы) — бренд и GR.

## Приоритизация (первые кандидаты после версии 3)
По ожидаемому влиянию на North Star: №1 открытые матчи → №4 рейтинг → №7 турниры → №11 рекомендации → №13 динамические цены → №19 видео. Остальное — по сигналам спроса.
